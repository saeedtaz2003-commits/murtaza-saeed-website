# Murtaza Insights — Mobile Charts & Data Presentation Standard v1.0

Applies to all future Insights articles and to approved presentation fixes on existing articles. Preserve approved calculations, values, chart types, series, order, conclusions, original assets and desktop appearance.

## Minimum rendered mobile sizes

- Category labels: 14 CSS px minimum; 15–16 px preferred.
- Key values: 16 CSS px minimum, bold.
- Axes and legends: 13–14 CSS px minimum.
- Source notes: 12 CSS px minimum.
- Comparison cards: compact, legible typography and spacing without omitting fields.

## Implementation

Design mobile-first, not by shrinking desktop raster charts. Use available content width; avoid clipping, horizontal page scrolling and unnecessary whitespace. Display values on or near bars. Preserve brand purple and adequate contrast. Responsive layouts may reposition labels but must not alter data, chart type, series or interpretation. Provide a full-size view or accessible data table for inherently dense charts.

## Publication gate

Check actual rendered article pages at 320, 375 and 430 CSS px and desktop. Verify charts, tables, source notes, labels, article-end controls, source/data parity, no clipping or horizontal overflow. Do not publish until mobile readability checks pass. Approved editorial content is locked; make only explicitly authorised presentation corrections.
